# Reader keys

Generated from `src/vim.ts`; do not edit.

| Keys | Does |
| --- | --- |
| `j` | Scroll down |
| `k` | Scroll up |
| `Ctrl-d` | Scroll half a page down |
| `Ctrl-u` | Scroll half a page up |
| `J` | Next page |
| `K` | Previous page |
| `Space / Shift-Space` | Next / previous page |
| `gg` | First page |
| `G` | Last page |
| `NG` | Go to page N |
| `/` | Search |
| `n` | Next search result |
| `N` | Previous search result |
| `+` | Zoom in |
| `-` | Zoom out |
| `=` | Reset zoom |
| `og` | Jump to a section |
| `ag` | Jump to an annotation |
| `Nt` | Select tool N: highlight, underline, note, text, image, ink, eraser |
| `Escape` | Back to selection |
| `dd` | Delete the selected annotation |
| `c` | Edit the selected annotation's comment |
| `y` | Copy the selected text |
| `C` | Column mode |
| `?` | Show this help |
| `q` | Close the reader |
