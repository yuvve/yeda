# Reader keys

Generated from `src/vim.ts`; do not edit.

| Keys | Does |
| --- | --- |
| `v` | Caret mode; again: select from the caret (visual); again: back to the caret |
| `h` | Caret: previous character |
| `l` | Caret: next character |
| `j` | Scroll down; caret: next line |
| `k` | Scroll up; caret: previous line |
| `w` | Caret: next word |
| `b` | Caret: word start |
| `e` | Caret: word end |
| `0` | Caret: line start |
| `$` | Caret: line end |
| `Ctrl-d` | Scroll half a page down |
| `Ctrl-u` | Scroll half a page up |
| `J` | Next page |
| `K` | Previous page |
| `Space / Shift-Space` | Next / previous page |
| `gg` | First page |
| `G` | Last page |
| `NG` | Go to page N |
| `/` | Search |
| `n` | Next search result; caret: move there |
| `N` | Previous search result; caret: move there |
| `+` | Zoom in |
| `-` | Zoom out |
| `=` | Reset zoom |
| `o` | Visual: other end of the selection; area: other corner |
| `og` | Jump to a section |
| `ag` | Jump to an annotation |
| `Nt` | Tool N (highlight, underline, note, text, image, ink, eraser); with a selection, highlight or underline it; in caret mode, a note, text box or image area at the caret |
| `Nc` | Colour N (yellow, red, green, blue, purple, magenta, orange, gray) for the selected annotations, else for the tools |
| `Enter` | Area: save the image annotation |
| `Escape` | Leave area, visual or caret mode, else back to selection |
| `]a` | Select the next annotation |
| `[a` | Select the previous annotation |
| `dd` | Delete the selected annotation |
| `c` | Edit the selected annotation's comment |
| `T` | Edit the selected annotation's tags |
| `y` | Copy the selected text |
| `C` | Column mode |
| `?` | Show this help |
| `q` | Close the reader |
